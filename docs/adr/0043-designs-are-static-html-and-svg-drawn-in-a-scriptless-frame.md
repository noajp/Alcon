# 0043 — デザインは静的な HTML と SVG で持ち、スクリプトの動かない枠で描く

## 背景

画面・カード・図版・図解などのデザインは、Figma のような専用の形式に閉じ、共有も閲覧もその道具に縛られてきた。Alcon ではノートもスライドも HTML で描いている。デザインも同じ形式で持てば、文書・スライド・デザインを一つの形式で扱え、AI がそのまま書いて直せ、実装へもそのまま渡せる。

まず、ボードに置けるウィジェットとして作る。

## 選択肢

形式:

1. 静的な HTML・CSS・インライン SVG（スクリプトなし）
2. AI アプリと同じく HTML・CSS・JS（動く）
3. 独自のベクター形式（図形の JSON）を作り、描画器を書く

描く場所:

- a. ブラウザの隔離した iframe（`sandbox=""`、ページ独自の CSP）
- b. サーバーで描いて画像にする

フォント:

- i. アプリが持つ決まった書体（自前で配信）
- ii. 外部のフォント配信（Google Fonts など）
- iii. 端末の書体だけ

## 決定

1・a・i。

- **形式**: 一枚のアートボードを `width`・`height`（CSS px）、背景色、使う書体、`html`、`css` で持つ（`Function/widget/design/model.ts`）。決まった大きさで描き、幅に合わせて縮小だけするので、どの画面でも同じに見える。スクリプト・イベント属性・埋め込みページ・外部への URL・`@import` は保存前と表示前に拒む（`parseDesign`）。画像は data: URL で埋め込む。
- **描く場所**: `sandbox="allow-same-origin"` の iframe に、`default-src 'none'` の CSP を持つ文書（`designDocument`）を入れる。スクリプト・フォーム・遷移は枠が止め、読み込めるのはアプリの書体と data: 画像だけ。同じ origin を許すのは書体をアプリと同じように読むためで、スクリプトが動かない限り危険はない（origin のない枠からは、ブラウザの制限で書体を取得できなかった）。拒否の検査は二重の守りで、主たる守りはこの枠。
- **フォント**: Inter・Noto Sans JP・Noto Serif JP・DM Sans・Space Grotesk・Playfair Display・Source Serif 4・JetBrains Mono を fontsource から取り、ビルド時に `public/design-fonts/` へ写す（`scripts/design-fonts.mjs`、一覧は `fonts.json`）。ダウンロードした HTML を別の場所で開いても書体が読めるよう、書体ファイルは CORS で誰でも読めるようにする（`next.config.ts`）。デザインを開いた人の情報が外部の配信元に渡らない。
- **保存**: ウィジェットの共有文書（ADR 0040）の `design` に、全員の現在のデザインと一つ前を置く。AI に頼んだ直しと依頼文は本人だけのもの（`widget_viewer_state`）で、「使う」と全員のデザインを置き換える。
- **AI**: Edge Function `generate-design` が Claude（`claude-opus-5-5`、構造化出力、拒否時のサーバー側フォールバック）にデザインの JSON だけを返させる。直すときは現在のデザインを渡し、頼まれていない部分は保つ。
- **渡す**: HTML と CSS のコピー、HTML ファイルのダウンロード。

## 理由

- 静的な HTML・SVG は、デザインが表すもの（画面）そのものの形式で、レイアウト（flex／grid）、文字組み、ベクター、トークン（CSS 変数）まで表せる。独自形式は描画器と変換を抱え、AI も実装も読めない。
- スクリプトを許さなければ、他人が置いたデザインが閲覧者の権限で何かを読んだり送ったりする余地がない。スクリプトの動く AI アプリのような、閲覧者ごとの接続の確認がいらない。
- 書体を自前で持てば、細部の再現が端末に左右されず、外部への依存と送信もない。

## 影響

- 写真のレタッチ、ブラシの描画、印刷向けの色管理は対象外。
- 手で直す編集（選択・移動・数値）はまだない。AI で直す。
- PNG／PDF の書き出しはまだない。枠の外で書体を埋め込む必要があり、次の段で扱う。
- 書体を増やすときは `fonts.json` と生成関数の一覧をそろえる（テストで確認）。
