# 議事録：「好き」でつながる招待制コミュニティ構想

- 日時：2026年10月17日（土）20:00〜21:35 ごろ
- 参加：TAKANORI（ヒナとの事前の議論を持ち込み）、Claude（壁打ち役）
- 目的：TAKANORI とヒナの2人で、社会にどんな価値を提供できるかを見極める
- 仮称：sukima（仕事と家のあいだにある、大人の余白）

---

## 1. 前提：2人のプロフィール

| 観点 | ヒナ | TAKANORI |
|---|---|---|
| 経歴 | アメリカン大学でマーケティングを専攻、看護学も学んだ | システムエンジニア |
| 現在の仕事 | 人材紹介の法人営業（リクルーティングアドバイザー）、人事コンサル的な業務 | システム開発 |
| 志向 | 人と人をつなぎ、人の「ワクワク」を引き出す場をつくりたい | クリエイティブが好きで、テクノロジーの素養もある |

- 役割分担の見立て：ヒナが「人を見て、つなぐ」、TAKANORI が「仕組みと見せ方をつくる」

## 2. 固まっている外枠

- 不特定多数ではなく、プライベート性が担保された空間を提供する（参考：NOT A HOTEL）
- 人がワクワクする体験を届ける
- テクノロジーは主役ではなく補助として使う
- ブランドとクリエイティブをしっかり確立する
- イベント運営会社や広告代理店のような受託ではなく、自分たちで生み出して届ける
- 表面的なものではなく、まだ満たされていない「痒いところ」に届く本質的な価値を目指す

## 3. 課題意識

- 社会人は職場と家の往復になりやすく、利害関係のないコミュニティが乏しい。その結果、寂しさや物足りなさを抱えている
- マッチングアプリ、ランニングコミュニティ、HYROX が伸びているのは、この需要の表れ
- これらはどれも「出会うための口実」（恋愛、走る、競技）を提供している
- フリーランスやインフルエンサーの増加は、モヤモヤを行動に移した人が増えた結果と見ている。一方で「何もしない安定」を選ぶ人もいて、二極化が進んでいる

## 4. ターゲットとペルソナ

- 狙うのは、飛び出しもせず、安定にも振り切れていない「間で揺れている層」
  - 数が多いのに、受け皿になる場がほとんどない
- その中でも、本気の「好き」・こだわり・センスを持っている人
- ペルソナ例：大企業で安定して働く会社員。バイオリンが得意で音楽活動もしたいが、仲間がいない。結局、家でひとりで弾いていて、アウトプットにつながっていない
- 痒み：才能や情熱があるのに、それが誰にも届いていない

## 5. 既存サービスとの位置づけ

- 会員制・ハイクラス向けという枠だけなら、市場はかなり埋まっている
- 既存サービスは2つに分かれている
  - 高額でステータス重視の型：アークヒルズクラブ、Soho House、紹介制レストランなど
  - 気軽だが参加者の質がまちまちな型：Timeleft、異業種交流会、ランニングクラブなど
- 空いているのは、30代前後の上質な社会人が肩書き抜きで本音を話せて、人の組み合わせまで設計されている場
- 調べればすぐ中身が分かる時代なので、参加前から価値が伝わる設計が必要
  - 誰が来るか、なぜその組み合わせか、何が持ち帰れるか、誰が主宰しているか

## 6. コンセプトとサービスの形

- コンセプト：会社員の隠れた「好き」を、作品と仲間に変える場所
- 事前に伝える約束（案）：「あなたの『好き』を、ひとりで終わらせない」
- サービスの流れ
  1. 発掘：ヒナが面談で「好き」とこだわりの深さを聞く。これが入会審査を兼ねる
  2. 結合：相性のよいメンバー同士を少人数で引き合わせる
  3. 発表：サロンコンサート、小さな展示、一夜限りのレストランなど、外に出す場をつくる
  4. 記録と発信：TAKANORI のクリエイティブで写真・映像に残す。本人の実績と、サービスの広告を兼ねる
- ジャンルの掛け合わせ例
  - 料理 × ワイン × 写真 → 一夜限りのレストラン
  - 音楽 × 建築 × 映像 → 古民家のサロンコンサート
  - 文章 × イラスト → ZINE（小冊子）と朗読会
  - アート × 空間 → 閉店後のギャラリーでの一晩だけの展示

## 7. 縁が循環する仕組みと「場所」

- 出会う → 体験する → 仲間になる → 次を企画する → 新しい人が来る、の循環をつくる
- メンバー自身が企画する側に回るほど、2人の手間が減り、コミュニティが自然に広がる
- 体験できる場所があると、ブランドが目に見え、縁が途切れにくく、収益源も増える
- ただし固定費が重いので、場所は段階的に持つ
  - 最初：ギャラリー、古民家、閉店後のレストランなどを毎回借りる
  - 次：相性のよかった場所と提携する
  - 軌道に乗ったら：自分たちの拠点を持つ
- 「場所は前日まで秘密」という演出もありえる

## 8. 収益モデル（仮置き）

- 会員費（土台）：入会金3万円、月額1.5万円
- 発表イベント：外部も参加できるチケット制（5,000〜1万円）。新規会員の入口になる
- 企業向けプログラム（一番の伸びしろ）：社員の「好き」や才能を引き出すプログラムを、人的資本経営や社内活性化として販売する（1社あたり年200〜500万円を想定）
- 作品・スキルの仲介（将来）：メンバーの作品・演奏・撮影を企業やイベントにつなぎ、手数料を受け取る
- 会員費だけで大きく伸ばすのは難しい。会員コミュニティは質の証明と実績づくりと割り切り、企業向けで稼ぐ二層構造にする
- 数字はすべて仮置きで、検証が必要

## 9. ブランドの方向性

- 最初のデモは Timeleft のようなポップな方向で作った
- その後、方向を修正した
  - 尖りすぎず、出会い目的の層に刺さるほどマス向けにもしない
  - 少し格式があり、洗練された感覚にする
  - 参考：Arc'teryx や On のコミュニティのクリエイティブ、theuglyhouse.studios
- 修正後のトーン：ほぼ黒と生成りの2色、アクセントにライムを1色。見出しは明朝体、ラベルは等幅の英字
- 「出会い」は前に出さず、「好きを深く持つ大人の食卓」として打ち出す
- ハウスルールを明記する（招待制、1卓6人、場所は前日に連絡、名刺は出さない、営業と勧誘はお断り）

## 10. マッチングの考え方

- 「同じ好き」ではなく「隣り合う好き」で組む
  - 同じ：知識比べやマウント合戦になりやすく、炎上のリスクが一番高い
  - 隣り合う：共通の入口がありつつ教え合える。一番盛り上がる
  - 遠い：新鮮だが、話が続かないことがある
- MBTI は話題の入口として使い、マッチングの中心には置かない。見るのは会話のスタイル
  - 話し手か聞き手か、深掘りする人か広げる人か、場を回す人か乗る人か
- 炎上を防ぐ一番の指標は「開かれ度」（自分と違う楽しみ方を面白がれるか）。面談で見極める
  - 開かれ度が高い人：どんなにニッチでも通常の卓へ
  - こだわりが強く閉じ気味の人：発表する側（奏者、シェフなど）に回ってもらう
  - 明らかに合わない人：入会をお断りする
- 1卓6人の組み方
  1. ゆるい共通テーマを1つ置く
  2. 全員が少なくとも2人と何かしら重なるようにする
  3. 同じ分野の熱狂的な人は1卓に1人まで
  4. つくる側と味わう側を混ぜる
  5. 場を回す人を1〜2人、聞き手を2人ほど入れる
  6. 前に同じ卓だった人とは組まない
- 会の後に「また会いたい」を互いに選び、両方が選んだときだけつながる。このデータが、そのままアルゴリズムの精度と他社が真似できない資産になる

## 11. 作ったもの

- LP とアプリ導入画面のデモ（Claude のデザインキャンバス上）
  - LP：コンセプト、参加のステップ、対象の人、体験の例、縁の循環、ハウスルール、料金
  - 導入画面：求めるもの → 好き（最大3つ）→ その好きとの距離 → 業界 → 年代 → 連絡先 → 受付完了（面談へ）

## 12. 決まったこと

- 事業の核は「隠れた『好き』を持つ会社員どうしを、隣り合う好きで引き合わせ、体験と作品にする招待制の場」
- ターゲットは「飛び出しも安定もしていない、本気の好きを持つ層」
- ブランドは、ポップではなく、静かで格式のある方向で進める
- 最初は手作業で回し、仕組み化は後からにする
